# 原版 config.json 迁移

设置页的“导入原版配置”先选择 JSON，再显示迁移报告。选择文件和取消均不修改当前配置；“备份、导入并重启”会替换当前用户/便携配置，并启动新的应用进程。正在缩放或申请全局快捷键时拒绝安装，需先结束对应操作。

现有配置原字节备份在同目录 `desktop-settings.json.before-import-<UTC时间>-<随机标识>.json`。写入使用临时文件与替换；进程启动请求失败时恢复原字节，没有旧配置则删除此次新建的配置。如果其他进程已经修改新配置，不覆盖其他写入者，保留备份并报告回滚失败。系统成功创建进程不代表新应用已经完成 GUI/图形初始化；该后续阶段的故障还没有自动健康检查或回滚。

支持迁移：语言、主题、倒计时、托盘偏好、保持常亮、FP16、禁用置顶/允许最大化窗口、光标空闲隐藏/倍率/插值/速度补偿、重复帧/最低帧率、四项快捷键偏好（含截图）、完整模式数组及各默认/应用配置的模式引用、捕获方式、初始窗口比例、独立工具栏状态、限帧、裁剪、输出对齐及有效截图模板。支持原版 `hotkeys` / `scalingProfiles` / `downCount` / `showTrayIcon` 和全局 overlay 工具栏/截图位置的旧格式。

- 应用配置不继承默认配置的裁剪/比例等局部值，与原版独立默认值一致。
- 原版模式数组下标在迁移时转为稳定 ID。无效/未选择的模式转换为一个不可运行的空模式，提示重新选择，不能静默换成 Lanczos 或原样显示。
- 不可用的效果/捕获方式仍不可用。不会自动换成另一种算法或本机后端。
- 全局快捷键只转换偏好，不申请系统权限或注册；需在主页明确启用。禁用/当前无法表达的原版绑定会留在原始数据中，报告说明对应偏好使用默认值。原版允许、而本移植不能表达的相互重复绑定会导致校验失败，需先在源配置中解决。
- Windows 路径、窗口类名、打包应用 ID 和原始参数完整保留；不生成假的 Linux/macOS 绝对路径，Windows 手动缩放入口已接原版桌面窗口规则匹配（实际目标验证待完成），其他平台不套用 Windows 规则；自动启动与打包窗口身份解析仍未接。详见 [应用匹配](application-matching.md)。应用页显示原规则和未应用的原始参数，需手动选择本机程序、核对本机参数。选择前启动/打开程序目录禁用。
- 非 Windows 主机的原截图目录及相对目录不映射到当前工作目录，使用本机默认目录并给出迁移说明。Windows 只采用已完全限定的原目录。
- DXGI 显卡身份、自动缩放启动、3D 游戏/触控、窗口位置、更新及尚未实现的开发者字段等目前不应用；完整源对象保存在 `OriginalConfiguration`，每个应用身份另存 `OriginalProfile`，源文件不修改。报告逐字段列出未应用设置。保留数据不等于这些功能已经实现。

还可以不启动 GUI，先转换到一个新文件供审查：

```sh
Magpie.Desktop --migrate-original-config /path/to/config.json /path/to/new-desktop-settings.json
```

该命令拒绝覆盖已存在的目标，包括源文件，且不会修改当前运行配置。JSON 输入上限 4 MiB，拒绝重复属性、错误类型/范围和超出当前模式/配置容量的数据；支持原版 BOM、注释和尾逗号。当前模式容量 100（未选择模式的保留项也计入），应用配置容量 100。完整字段按 JSON 值保留，JSON 注释/原始排版不保证保留；备份文件则保留旧文件原字节。

本轮证据见 `artifacts/desktop/original-config-test-summary.json`。Linux NativeAOT 核心/文件事务和私有 Wayland UI 已验证；文件选择和重启使用可拒绝替身，未调用用户桌面选择器、未重启真实应用。Windows/macOS 的本轮编译、原生文件选择与新进程 GUI 恢复尚未验收，三平台所有交互缺口仍未完成。
