# Profiler 计时统计

对照原版 `OverlayDrawer::_DrawProfiler`，统计发布与帧到达分离：首个有效采样立即显示；只有新 GPU 帧到达且距上次发布严格超过 500 ms，才发布此前累积的均值。触发发布的当前帧属于下一个统计区间。未执行或耗时不大于 0.001 ms 的 pass 不计入分母；某个 pass 在区间内没有有效采样时，保留上次显示值。

工作线程的每次成功 UI 画面提交都会交付相应 GPU 样本，不再只在每秒性能汇总时取最后一次采样。native 执行序号用于去重：计时文本刷新、效果/pass 视图切换、无新帧时的汇总及截图导出都不会再次累积同一帧。已经发布的数组独立于输入快照；图形链的效果/通道映射变化、序号回退、关闭或不可用状态会清理统计。

显示的效果总耗时为 pass 均值之和。最终 barrier/query 尾段仍单独显示，避免将尾段误当作某个算法的执行时间。逐 pass 文本附上原始 MagpieFX 描述，仍保留 pass 序号，便于区分相同描述的重复 pass。

验证范围：纯模型覆盖严格时间边界、首帧、前一区间、触发帧归属、重复序号、空闲、零/阈值样本、保留旧值、效果/pass 映射及引擎/关闭/时钟回退。隔离 UI 用真实 Vulkan 连续采样、强制帧调度和等待来检查去重与实际显示均值；源像素和帧调度为测试夹具。完整浮动 profiler 的布局、拖动、时间条、悬停联动、GPU/捕获元信息及三平台实际桌面交互仍需继续移植验收，不能把本统计阶段称为完整 profiler 完成。


2026-10-26 验证：最终 Linux NativeAOT 核心、交互模型与七项中英私有 Wayland UI 通过。实际输出测试共用生产 `PresentProcessedFrame` 路径，覆盖连续三次真实 GPU 采样、50 次重复刷新去重、前一区间平均值、关闭 profiler 及停止后拒绝提交且不改统计。已查看保持工具栏可见、滚动到真实计时文本的输出截图。逐 pass/普通阶段导出和原有下拉一起回归。

录制器额外等待各 popup 的三个 native animation frame，解决曾被外部取证器检出的“首次 buffer 尚未 ack/commit 就截图”；仍由 Wayland 协议解析器严格检查配置已确认和提交，没有跳过或放宽取证要求。报告 `artifacts/desktop/profiler-averages-test-summary.json`。本轮原生源码未变，未重复计算旧 CTest 证据；Windows/macOS 当前托管变更的目标构建待 CI，真实源捕获、输入送达和原生指针事件未在本轮测试。


## 时间条与耗时行

平均计时现在同时驱动比例时间条和可滚动的耗时行。普通模式只显示效果；只有开发者模式且至少一个效果有多个 pass 时，才提供切换按钮。单效果折叠视图不显示时间条；pass 视图保留效果总计行，下面按原始描述排列通道。零/阈值以下的项保留耗时行，但不分配色块，全部为零时使用空占位，不虚构百分比。

色块宽度按有效项耗时比例分配，不设最小宽度；文字放不下就省略。悬停或键盘聚焦的项显示四舍五入的占比，并与耗时行高亮联动。提示包含效果/pass 名称、三位小数毫秒值与百分比。采用原版七色调色板，按图形链稳定分配，避免视图切换和平均值刷新导致重新随机换色；不复刻依赖 C++ 标准库 hash/random 实现的具体随机颜色顺序。

开发者模式在没有新 GPU 帧时关闭，也会清理旧 pass 视图。计时行/色块从工具栏 caption 命中区排除，避免交互触发窗口移动。隐藏 profiler 或刷新图形链时关闭旧提示并清理内容；周期更新保留同一 pass 的键盘焦点。提示位置按内容区到原生呈现根的实际视觉变换计算，不猜测窗口阴影/标题栏高度。

本节目标是移植原版比例时间条与列表交互；独立浮动 profiler 的窗口布局、拖动、捕获/GPU 元信息和完整真实三平台鼠标/焦点行为继续保留为缺口。本阶段最终验证结果见下面记录。


2026-10-26 时间条阶段：Linux NativeAOT 核心、模型及八项中英私有 Wayland UI 验证通过。模型验证原始描述/通道顺序、普通/开发者门控、占比、零/阈值占位、重复效果身份及颜色稳定性。隔离 UI 用实际 CuNNy→nearest Vulkan 时间戳验证按测量值分配的实际布局宽度，行/色块的合成指针悬停、键盘 focus、模式切换、设置外部修改同步、caption 排除和关闭清理。宽/窄输出的真实 tooltip 经外部 Wayland ack/commit 与内容边界验证，再合成到同一输出内容截图；已查看图像。录制等待正常 tooltip fade-in 完成，以免截到半透明过渡。

最终结果与二进制散列记录于 `artifacts/desktop/profiler-timeline-test-summary.json`；实际源像素、帧调度及输入事件为注入测试。这里不把布局/事件模型算作系统鼠标、源输入送达或所有平台 GPU 验收。C++ 与 shaders 本轮未变，原生 CTest 不重复计作本轮新证据。
